#Бие даалт 1 
Сэдэв №13: Өвлийн хүйтэн
Энэ бие даалтаар Flowgorithm ашиглан 7 хоногийн цаг агаарын тайланг боловсруулж, цельсийг фаренгейт рүү хөрвүүлэх, хүйтний түвшинг ангилах, хувцасны зөвлөмж гаргах болон хамгийн хүйтэн өдрийг олох алгоритм боловсруулсан.
## AI ашигласан тухай
Энэхүү бие даалтыг гүйцэтгэх явцад ChatGPT-ийг туслах зорилгоор ашигласан. Тухайлбал, Flowgorithm дээр блок-схем байгуулах, C хэлний кодыг алхам алхмаар боловсруулах, алдааг ойлгох, GitHub дээр файл байрлуулах болон программыг турших аргачлалын талаар зөвлөгөө авсан. AI-ийн тусламжтайгаар боловсруулсан кодыг OnlineGDB орчинд ажиллуулж, үр дүнг шалгасан. Мөн кодын үндсэн үйлдлүүдийг ойлгож, тайлбарлахад анхаарсан.
